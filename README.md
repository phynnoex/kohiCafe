# ☕ KohiCafe – Modern E-Commerce Frontend

A fully responsive **e-commerce web application** built with **React and TypeScript**, featuring **real-time data fetching with Firebase** and **session-based cart persistence** for a seamless user experience.

---

## 🚀 Live Demo

🔗 https://phynnoex.github.io/kohiCafe/

---

## 📌 Overview

KohiCafe is a frontend-focused e-commerce application that simulates a real-world online café experience. The application demonstrates **dynamic data handling, persistent UI state, and scalable frontend architecture**.

Key highlights include:

* Real-time product data integration using **Firebase**
* Persistent cart functionality using **session storage**
* Scalable and reusable component architecture
* Accessibility-first UI design (WCAG compliant)

---

## ✨ Features

* 🔥 **Real-Time Data Fetching (Firebase)**
  Integrated Firebase to fetch and manage product data dynamically, enabling real-time updates and scalable data handling

* 🛒 **Persistent Shopping Cart (Session Storage)**
  Implemented cart functionality with session storage, allowing users to retain their cart state across page refreshes within a session

* 🔄 **State-Driven UI Architecture**
  Managed complex UI state across components to ensure consistent and predictable data flow

* 📱 **Fully Responsive Design**
  Optimized for mobile, tablet, and desktop devices

* 🎨 **UI/UX Designed in Figma**
  Translated high-fidelity designs into a production-ready interface

* ♿ **Accessibility-Focused Implementation**
  Applied WCAG standards for color contrast, layout, and usability

## 🧠 Key Engineering Highlights

* Implemented **client-side persistence using session storage**, ensuring cart data survives page reloads without requiring a backend
* Designed **data-fetching logic with Firebase**, enabling dynamic content updates and scalable integration
* Structured application using **modular, reusable components**, improving maintainability and scalability
* Managed **cross-component state synchronization** for cart and product data
